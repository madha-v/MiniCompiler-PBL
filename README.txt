# MiniCompiler-PBL
Enhanced Mini Compiler for Custom C-Like Language using Python and PLY

This project is a Project Based Learning (PBL) mini compiler developed for Compiler Design course.  
It implements major phases of a compiler including lexical analysis, syntax analysis, semantic analysis, intermediate code generation, code optimization, and target code generation.

---

## 📌 Features

- Lexical Analysis using PLY (Lex)
- Syntax Analysis using PLY (Yacc)
- Semantic Analysis (variable declaration checking)
- Symbol Table Generation
- Three Address Code (TAC) Generation
- Simple Code Optimization
- Target Code Generation (Assembly-like)
- Supports arithmetic expressions
- Supports declaration, assignment, and print statement
- Parentheses supported

---

## 🛠 Technologies Used

- Python 3.x  
- PLY (Python Lex-Yacc)  
- Windows OS

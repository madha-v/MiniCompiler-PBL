
MINI COMPILER PROJECT (WINDOWS)

Requirements:
1. Install Python 3.10 or above
2. Open Command Prompt
3. Run: pip install ply

How to Run:
1. Extract zip file
2. Open folder MiniCompiler
3. Open Command Prompt in this folder
4. Run command:
   python main.py

Enter your program, for example:

int a = 10;
int b = 20;
c = a + b * 2;

Press Enter on empty line to finish.

Output will display:
Symbol Table
Three Address Code
Optimized Code
Target Code
